KeyboardForge

Click a key to edit it. Drag a symbol from the palette onto a key to set the currently selected level. Use the Level selector above to choose which shift level the keycaps are displaying. Keys show the actual character they produce; a dashed border marks a dead key (it modifies the next keystroke rather than producing a character by itself). Hover a key to see its technical keycode and symbol name.
